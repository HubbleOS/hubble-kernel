---
title: System Calls Overview
---

The HubbleOS syscall layer exposes kernel services to user space through a small numeric ABI.

The generic syscall table lives in `kernel/syscalls/syscall.c`. The x86-64 entry path lives in `arch/x86/kernel/syscalls/`.

## Syscall Numbers

Kernel-side syscall numbers are declared in `include/hubble/syscall.h`.

Numbers below 500 follow the Linux x86_64 ABI so static libc binaries
(busybox) run unmodified. Kernel-private calls live at 500 and above:

| Number | Name | Handler |
| --- | --- | --- |
| 500 | `SYS_spawn` | `sys_spawn` |
| 501 | `SYS_spawn_file` | `sys_spawn_file` |
| 502 | `SYS_module_load` | `sys_module_load` |
| 503 | `SYS_module_unload` | `sys_module_unload` |

`SYSCALL_COUNT` is currently 512.
