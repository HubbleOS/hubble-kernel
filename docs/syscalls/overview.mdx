---
title: System Calls Overview
---

The HubbleOS syscall layer exposes kernel services to user space through a small numeric ABI.

The generic syscall table lives in `kernel/syscalls/syscall.c`. The x86-64 entry path lives in `arch/x86/kernel/syscalls/`.

## Syscall Numbers

Kernel-side syscall numbers are declared in `include/hubble/syscall.h`.

| Number | Name | Handler |
| --- | --- | --- |
| 1 | `SYS_write` | `sys_write` |
| 2 | `SYS_read` | `sys_read` |
| 3 | `SYS_mmap` | `sys_mmap` |
| 4 | `SYS_open` | `sys_open` |
| 5 | `SYS_close` | `sys_close` |
| 6 | `SYS_spawn` | `sys_spawn` |
| 7 | `SYS_spawn_file` | `sys_spawn_file` |
| 8 | `SYS_lseek` | `sys_lseek` |

`SYSCALL_COUNT` is currently 256.

Note: `usr/include/sys/syscall.h` currently defines user-side numbers only through `SYS_spawn` and does not include `SYS_spawn_file` or `SYS_lseek`.
